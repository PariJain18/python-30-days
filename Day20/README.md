## What is does
1. employee.py
   - Creates an Employee class.
   - Stores employee names.
   - Counts total employees using a class attribute.

2. temperature_class.py
   - Creates a Temperature class.
   - Uses @property and setter.
   - Checks temperature below absolute zero.

3. date_parser.py
   - Creates a Date class.
   - Uses @classmethod.
   - Converts a date string into day, month, and year.
